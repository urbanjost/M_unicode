SYNOPSIS

subroutine compile_expr_cp(expr_cp, prog, ierr, var_names, ufuncs) 

    integer(int32), intent(in) :: expr_cp(:)
    type(compiled_expr), intent(out) :: prog
    integer, intent(out) :: ierr
    type(cp_string), intent(in), optional :: var_names(:)
    type(user_func), intent(in), optional :: ufuncs(:)

DESCRIPTION

compile_expr_cp parses the mathematical expression stored in expr_cp (a 1D array of 32-bit Unicode codepoints) and emits a flat array of virtual machine instructions inside prog.
o var_names maps identifier names to 1-based variable indices (1 .. size(var_names)). Matching is strictly case-sensitive.
o ufuncs registers custom Fortran callback functions (user_func structs containing name%cp, nargs, and procedure pointer fn).

OPTIONS
expr_cp
  The expression to be compiled
var_names(:)
  variable names
ufuncs
  user-defined functions

RETURNS
prog
  the compiled expression
ierr
  Set to 0 on success, or a non-zero error code (1–11) on failure.
