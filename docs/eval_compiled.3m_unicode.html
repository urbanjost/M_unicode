NAME
eval_compiled(3f) - [M_unicode:EVAL] execute a compiled bytecode expression with scalar or array variables (LICENSE:MIT)

SYNOPSIS

subroutine eval_compiled(prog, result, ierr, vars) 

     type(compiled_expr), intent(in) :: prog
     real(real64), allocatable, intent(out) :: result(:)
     integer, intent(out) :: ierr
     type(var_value), intent(in), optional :: vars(:)

DESCRIPTION

eval_compiled executes the instruction stream in prog without recursion. Each element vars(i)%val(:) supplies the runtime value for the i-th variable declared in var_names during compilation. 

 + Scalars are passed as 1-element arrays (vars(i)%val = [1.0_real64]).
 + Arrays of length N broadcast automatically against scalars, producing
   an output array result of length N.

OPTIONS

RETURN VALUE

Allocates result with the computed scalar (length 1) or array (length N) and sets ierr = 0. On runtime errors (such as division by zero or out-of-bounds indexing), ierr is set to 3, 10, or 12–15.

EXAMPLES

Sample program 

   program demo_eval_compiled
   use M_unicode
   end program demo_eval_compiled
