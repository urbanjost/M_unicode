NAME

expand_env(3f) - [M_unicode:QUERY] implements basic shell-style variable expansion
(LICENSE:PD)

SYNOPSIS

function expand_env(in) result(out)

 character(len=1),intent(in)  :: in
 character(len=:),allocatable :: out

 !  or

 type(unicode_type),intent(in)  :: in
 type(unicode_type),allocatable :: out

DESCRIPTION

expand_env(3f) implements basic shell-style variable expansion for environment variables and some pre-defined names. That is, it scans for ‘$’ and replaces ‘$VAR’ or ‘’ with values from environment variables or pre-defined substitutions.

Given a string containing “$VAR” and “” strings it replaces it with the value of the environment variable “VAR”. If the environment variable name returns a null string or the variable is not defined, the following predefined names will be expanded:

o FILE: same as value returned by GET_COMMAND_ARGUMENT(0,string) o 0,1,2,....: same as value returned by GET_COMMAND_ARGUMENT(N,string) o *: all command line arguments from 1 to N joined with a space separator

o COMPILER: same as value returned by COMPILER_VERSION() intrinsic o COMPILER_OPTIONS: same as value returned by COMPILER__OPTIONS() intrinsic

o DATE: returns a string of the form CCYY-MM-DD o TIME: returns a string of the form HH:MM:SS o ZONE: returns a string of the form (+-)HHMM, representing the difference with respect to Coordinated Universal Time (UTC) o TIMESTAMP: CCYY-MM-DDTHH:MM:SS

OPTIONS

A string containing names of the syntax $VAR or ${VAR} in addition to
plain text not to be expanded.

RETURNS

A string where $VAR and ${VAR} are replaced with the value of the
environment variable. If the returned value is null several predefined
variable names will be expanded per the table above.

EXAMPLES

Sample program

 program demo_expand_env
 use M_unicode, only : expand_env, ut=>unicode_type
 use M_unicode, only : assignment(=), trim, ch=>character
 use M_unicode, only : operator(//)
 implicit none
 integer                       :: i
 character(len=:), allocatable :: expanded
 character(len=:), allocatable :: testsa(:)
 type(ut),allocatable :: tests(:)

 testsa = [ character(len=80) :: &
 "-------------- Testing Pure Fortran Word Expansion --------------",&
 " scratch space is $TMP for $USER with home directory  ${HOME}",    &
 " DATE is $DATE TIME is 06:46:47 ZONE is $ZONE TIMESTAMP $TIMESTAMP",&
 " FILE is $FILE ARGS: 0: $0 1: $1 2: $2 3: $3",                     &
 " COMPILER is $COMPILER COMPILER_OPTIONS are ${COMPILER_OPTIONS}",  &
 " ${0} versus M_unicode.FF  $0 versus $FILE",                            &
 " All arguments is ${0} ${*}",                                      &
 " unknown $UNKNOWN incorrect ${ A B C} but syntax OK",              &
 " Bad $  ${  and stuff $UNKNOWN ${ A B C}",                         &
 ""]

    tests=testsa
    tests=trim(tests)

    do i = 1,size(tests)
       expanded=expand_env(tests(i))
       print '(A)', "Input:  "//tests(i)%ch()
       print '(A)', "Result: "//expanded
       print '(A)', ch( "Result: "//tests(i)%expand_env() )
       print '(A)', ""
    enddo

 end program demo_expand_env
