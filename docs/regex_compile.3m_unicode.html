DESCRIPTION

Compiles a UTF-32 regular expression pattern into NFA bytecode.

See M_unicode__regex(3) for a full description of regular expression syntax.

The M_unicode__regex(3) module (accessed via the M_unicode(3) module) compiles regular expression patterns into Nondeterministic Finite Automaton (NFA) bytecode and executes them over arrays of UTF-32 scalar codepoints (ie.‘integer(int32)‘arrays). Because matching operates directly on Unicode codepoints rather than raw UTF-8 bytes, multi-byte characters (accented Latin, CJK, emoji, symbols) are indexed and matched as single characters without splitting byte sequences.

For convenience the procedures are generic and two other types are allowed -- TYPE(UNICODE_TYPE) variables and CHARACTER variables may be used whee CODEPOINTS(integer arrays composed of valid Unicode codepoint values). ae used.

For the CHARACTER mode the same entities are all CHARACTER variables.

For the STRING mode all the same entities are all TYPE(UNICODE_TYPE).

For the CODEPOINT mode all pattern compilation, text matching, and string
replacement operate directly on arrays of UTF-8/UTF-32
  scalar codepoints (integer(int32)).
Helper functions utoc(3) and ctou(3) convert between standard UTF-8 encoded Fortran character strings and codepoint arrays.

OPTIONS

pattern
  array of Unicode codepoints representing the regex.

OUTPUT

re inspect re%valid before passing re to regex_search or regex_replace. Invalid patterns return re%valid = .false. without aborting.
