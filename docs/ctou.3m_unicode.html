NAME
ctou(3f) - [M_unicode:CONVERSION] convert codepoints to UTF-8 CHARACTER string (LICENSE:MIT)

SYNOPSIS

pure function ctou(codepoints) result(utf8) 

    integer,allocatable,intent(in) :: codepoints(:)
    character(len=*),intent(out)   :: utf8

CHARACTERISTICS
o CODEPOINTS is of default INTEGER kind
o UTF8 is a CHARACTER variable

DESCRIPTION

ctou(3f) takes an integer array of Unicode codepoint values and generates a scalar CHARACTER variable containing bytes representing UTF-8-encoded data.

OPTIONS

o CODEPOINTS : An INTEGER array of Unicode codepoint values representing the glyphs to be encoded as UTF-8 data
o UTF8 : Scalar CHARACTER variable containing a stream of bytes containing data encoded as UTF-8 text.

EXAMPLES
Sample program 

   program demo_ctou
   use m_unicode, only : ctou
   implicit none
   !’Noho me ka hau’oli’ !(Be happy)
   integer,parameter :: codepoints(*)=[ &
      & 78,111,104,111,&
      & 32,109,101, &
      & 32,107,97, &
      & 32,104,97,117,8217,111,108,105]
   character(len=:),allocatable :: string
   character(len=1),allocatable :: bytes(:)
   character(len=*),parameter   :: g=’(*(g0,1x))’
   character(len=*),parameter   :: z=’(a,*(z0,1x))’


     write(*,g)’CODEPOINTS:’, codepoints
     write(*,z)’HEXADECIMAL CODEPOINTS:’, codepoints
     string = ctou(codepoints)
     write(*,g)’STRING:’, string
     write(*,g)’length in glyphs ’, size(codepoints)
     write(*,g)’length in bytes  ’, len(string)


   end program demo_ctou
Results: 

    > CODEPOINTS: 78 111 104 111 32 109 101 32 107 97 32 104 97 117 ...
    > 8217 111 108 105
    > 48 4E 6F 68 6F 20 6D 65 20 6B 61 20 68 61 75 2019 6F 6C 69
    > STRING:Noho me ka hau’oli
    > length in glyphs   18
    > length in bytes    20
