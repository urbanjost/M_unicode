SYNOPSIS

subroutine differentiate_compiled(prog, var_idx, dprog, ierr) 

    type(compiled_expr), intent(in)  :: prog
    integer, intent(in)              :: var_idx
    type(compiled_expr), intent(out) :: dprog
    integer, intent(out)             :: ierr

DESCRIPTION

differentiate_compiled(3) reconstructs an abstract syntax tree (AST) from prog, computes its exact analytical partial derivative with respect to variable index var_idx, performs algebraic constant folding and identity simplification, and compiles the resulting derivative AST into dprog.

Supported rules include sum, difference, product, quotient, general power (\(f^{g}\)), chain rule for elementary trigonometric/hyperbolic/exponential/logarithmic functions, sum(), and piecewise if().

OPTIONS

RETURN VALUE

Populates dprog and sets ierr = 0. Sets ierr = 16 if prog contains non-differentiable operators (such as floor or custom user_func callbacks).
